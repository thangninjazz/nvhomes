# NVHome SaaS Platform

Hệ thống quản lý CRM và nội thất cao cấp.

## Triển khai (Deployment)
Dự án được triển khai bằng Docker và tự động hóa qua GitHub Actions.

### Các thành phần:
- **Frontend**: Next.js (Port 3000)
- **Backend**: .NET 10 (Port 5232)
- **Database**: PostgreSQL (Port 5432)
